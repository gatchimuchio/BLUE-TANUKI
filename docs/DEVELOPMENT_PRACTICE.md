# BLUE-TANUKI 開発作法の参照先

本ファイルは旧リンク用の案内であり、独立の規範や工程履歴を持たない。作業時は [`AGENTS.md`](../AGENTS.md) と [`作業標準要領.md`](作業標準要領.md) に従い、最新版の仕様書・工程表・施工指示書は [`QE_CURRENT_AUTHORITY.md`](QE_CURRENT_AUTHORITY.md) の一か所で固定する。
