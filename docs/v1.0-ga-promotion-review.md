## 日本語基底 gate

通常状態は次で確認する。

```bash
pnpm validate:japanese-base
```

既存移行負債がある間、次は fail-closed しなければならない。

```bash
pnpm validate:japanese-base -- --strict
```

owner GO fixture または decision file があっても strict gate を迂回できない。多言語局所例外は不可避性を台帳化し、移行負債を例外へ読み替えない。
