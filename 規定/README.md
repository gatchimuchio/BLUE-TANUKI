# BLUE-TANUKI 日本語基底規定

このディレクトリは、BLUE-TANUKI における意味形成、仕様化、実装、監査、公開を日本語から開始するための正本群である。

## 正本の読み順

1. [`00_日本語基底規定.md`](00_日本語基底規定.md) — 適用範囲、成立順序、例外、監査、再開放
2. [`01_基底語彙.md`](01_基底語彙.md) — BLUE-TANUKI の主要概念と既存識別子の日本語上の意味
3. [`02_資産分類と局所例外.md`](02_資産分類と局所例外.md) — 全資産の分類と例外成立条件
4. [`正本索引.json`](正本索引.json) — 正本、系列参照、適用状態の機械可読索引
5. [`局所例外台帳.json`](局所例外台帳.json) — 実務上やむを得ない多言語箇所
6. [`移行台帳.json`](移行台帳.json) — 例外ではない未解消の移行負債

## 現在の成立状態

- 日本語を唯一の基底規定言語とする規則: **成立**
- 既存の多言語資産を含むリポジトリ全体への適用: **成立**
- 既存の活正文書、操作面、コード内説明の日本語化: **移行中**
- P13 Owner GO / GA 公開判断: **凍結継続** (`public_claim_allowed=false`)

「規定成立」は、既存資産の翻訳がすべて完了したという意味ではない。未完了箇所は局所例外へ格上げせず、`移行台帳.json` に負債として保持する。

## 検証

```bash
pnpm validate:japanese-base
pnpm validate:japanese-base -- --strict
```

通常検証は、正本、例外台帳、移行台帳の整合と未登録負債の不在を確認する。`--strict` は移行負債が一件でも残る限り失敗し、GA 公開可能性を閉じたままにする。
